Privacy

What stays on your device

Forms, photos, signatures and sealed records are kept in your browser. No account is needed. Target: form content never leaves the device unless you share the copy file. The check below covers requests only. It does not look inside your browser storage.

What was checked

The path tests of this repository run the app in headless Chromium with Playwright 1.65.1 and record every request. In those runs, every request went to the address of the site itself, no request carried a body, and no page error or console error happened. Those runs had no beacon address set. The record of the check is in docs/kiro-log.md: the check for other addresses is in the row for task 9 of the counter-app spec, and the check for bodies is in the row for task 12.

Usage beacon

A build sends nothing about use unless it was built with a beacon address (VITE_BEACON_URL). When an address is set, the app sends only these events, each with the form id and with no id, no time and no form content in the body:

The server that receives a beacon also sees the request itself, such as the address it came from and the time it arrived. A build with no beacon address sends no beacon.

Sharing a copy

A copy file is one HTML file. If you send it to someone, that person can read all of it, including the photos and signatures.
