Privacy

What stays on your device

Forms, photos, signatures and sealed records are kept in your browser. You need no account. The aim is that form content never leaves your device unless you share the copy file. The check described below looks at requests only. It does not look inside the storage of your browser.

What was checked

We ran the app in Chromium with no window, driven by Playwright 1.65.1, and recorded every request it made. In those runs, every request went to the address of the site itself, no request carried a body, and no page error or console error happened. Those runs had no beacon address set. The results of these checks are written down in the project log: the check for requests to other addresses in one entry, and the check for request bodies in another.

Usage beacon

A build of the site sends nothing about use unless it was built with a beacon address. When an address is set, the app sends only the events below. Each message holds the name of the event and the id of the form type, and nothing else: no personal id, no time and no form content.

The server that receives a beacon also sees the request itself, such as the address it came from and the time it arrived. A build with no beacon address sends no beacon.

Sharing a copy

A copy file is one HTML file. If you send it to someone, that person can read all of it, including the photos and signatures.
