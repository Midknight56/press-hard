# Power session

This folder holds the input files for one session that uses the `press-hard` power.

- `inputs/rental-return-good.html` is a sealed rental return copy that was not changed.
- `inputs/rental-return-changed.html` is the same copy with the mileage text changed after sealing and no new seal.

Both files were written by `node mcp/scripts/make-demo-copies.ts` and copied here. `verify_copy` says `matches` for the first and `changed` for the second.
